# Python Basics

A collection of foundational programming concepts, exercises, and introductory scripts written in Python. This repository serves as a personal log of my coding journey and a reference guide for mastering core software engineering fundamentals.

## Repository Contents

This workspace contains practical implementations of baseline Python concepts, including:
* **Syntax & Variables**: Understanding data types, dynamic typing, and operations.
* **Control Flow**: Implementing decision-making logic using `if`, `elif`, and `else` statements.
* **Loops**: Working with iterative processes via `for` and `while` loops.
* **Functions & Logic**: Building reusable, modular blocks of code.

### Prerequisites
To run these scripts locally, make sure you have the latest version of Python installed on your system. You can verify your installation by running:
```bash
python --version
```

### Execution
1. Clone or open this folder in your development environment (Visual Studio Code).
2. Open your terminal and run any specific script by navigating to its file path:
```bash
python filename.py
```
